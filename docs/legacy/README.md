# โค้ดเดิม (เลิกใช้แล้ว — ห้ามนำกลับมาใช้)

ไฟล์ในโฟลเดอร์นี้คือระบบเดิมบน Google Apps Script ที่ถูกแทนที่ด้วยระบบใหม่ใน repo นี้
เก็บไว้เพื่อ **อ้างอิงพฤติกรรมทางธุรกิจ** ระหว่างช่วงเปลี่ยนผ่านเท่านั้น

| ไฟล์ | หน้าที่เดิม |
|---|---|
| `Codg.gs` | Apps Script backend: `doGet`/`doPost`, อ่าน/เขียน Google Sheet, ส่งรูปเข้า Telegram (ชื่อไฟล์สะกด `Codg.gs` ตามของจริงที่ deploy อยู่) |
| `index.html` | ฟอร์มฝั่ง client เรียก backend ผ่าน `google.script.run` |

## คำเตือน

- **ห้ามนำโค้ดนี้กลับมาใช้หรือพอร์ตบรรทัดต่อบรรทัด** — มีบั๊กและช่องโหว่ที่ทราบแล้ว 14 รายการ
  (ดู `docs/ADR-001.md` หัวข้อ "หนี้ทางเทคนิคที่ต้องล้างระหว่างย้าย")
- Telegram bot token ที่ hardcode อยู่ใน `Codg.gs` **ถือว่ารั่วแล้ว** และต้องถูก revoke ตอน cutover
- Apps Script deployment ตัวจริงยังต้องคงอยู่จนกว่าระบบใหม่รันจริงผ่านไปอย่างน้อย 2 สัปดาห์ (แผน rollback)
